# Episode 0008 Production Plan

## Problem

The episode must make the architectural distinction between retrieving relevant knowledge and constructing an answer through explicit reasoning.

## Principles

- Recorded presenter media is the timing authority.
- The Knowledge Model remains authoritative; retrieval technologies remain supporting strategies.
- Reasoning capabilities are identified before agent behaviour.
- A reasoning map is an explanation artefact, not a second knowledge store.
- Visual changes follow the argument and use the current presenter-era grammar.

## Capabilities

The visual sequence must explain semantic, relational and structured retrieval; relational, constraint, comparative, temporal and evidential reasoning; iterative Agentic RAG; the Knowledge Reasoning Layer; and reasoning-first agent design.

## Architecture

Fourteen continuous-audio scenes combine Presenter, Evidence, Diagram and Reflection archetypes. Shared registered D2 sources provide the knowledge reasoning flow, Knowledge Reasoning Layer, reasoning-before-agents progression, knowledge graph and reasoning map. The connected-knowledge example reuses the Episode 7 reasoning-context asset.

## Runtime

`prepare-presenter-v1.mjs` aligns the approved narrative to local Whisper word timings from the final recording, resolves deterministic reveal events, writes the render contract and produces British English subtitles. The shared episode renderer creates a 1080p/30 fps H.264/AAC publication file and review contact sheets.
