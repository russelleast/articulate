# Episode 0000 YouTube Thumbnail

The publication default is the presenter-led composition: Russell is part of the dark Focus Canvas rather than contained in a video rectangle. The headline remains `BUILDING AI-NATIVE ARCHITECTURE`, with restrained Articulate branding, architectural grid texture and the established rust/blue palette.

The earlier Companion-led A/B/C candidates remain archived in this directory. They are not regenerated by the presenter command and remain available through `render-thumbnails.mjs` when legacy rendering is required.

## Presenter-led default

`thumbnail.config.json` is the reusable episode-level contract. For a new or re-recorded presenter episode, copy the configuration and change:

- the episode ID, headline and series label;
- the real presenter media path and reviewed frame timestamp;
- frame placement only when the source framing requires it.

The default presenter treatment uses a soft luminance key to dissolve a black recording background into the Focus Canvas. It permits restrained exposure, saturation and sharpening adjustments, but does not synthesize or alter the presenter's likeness. Presenter-led episodes do not depend on a Companion asset.

Render Episode 0000 with:

```sh
make episode-0000-thumbnail
```

or:

```sh
node production/episodes/0000/publication/thumbnail/render-presenter-thumbnail.mjs
```

The deterministic renderer emits:

- `episode-0000-thumbnail.png` — final 1280 × 720 RGB publication image;
- `source/episode-0000-thumbnail.svg` — editable composition;
- `source/episode-0000-presenter-102_000.png` — extracted real presenter frame;
- `source/episode-0000-presenter-102_000-blended.png` — restrained background-blended presenter asset;
- `previews/episode-0000-thumbnail-320.png` — 25% review;
- `previews/episode-0000-thumbnail-160.png` — mobile-scale review;
- `previews/episode-0000-thumbnail-safe-area.png` — safe-margin and player-overlay review;
- `episode-0000-thumbnail-contact-sheet-presenter.png` — multi-size visual review.

The presenter-led format is the documented default for new and re-recorded episodes. Existing episode thumbnails are not changed automatically.
